# hi, i'm artemis 👋

I started coding at 14, in the 2020 lockdown, because my PC was too slow to run games. It could run a code editor, so here we are.

Now I'm a software engineer and DevRel at [NOFire AI](https://www.nofire.ai/), writing Go and TypeScript, and I explain code on camera to about 600k people a month as [@artemis.codes](https://www.instagram.com/artemis.codes/).

### things that are true

- I got my first developer job from a video about how I studied for my university entrance exams.
- I've given talks at DevConf.US, SREday San Francisco, React Summit and Conf42, mostly about what happens when AI-written code meets production.
- 4 hackathon wins out of 15, including OpenAI Build Week in Athens.
- I co-run [Athens Python Meetups](https://www.meetup.com/athens-python-users-meetup/). Come say hi.
- I'm still studying CS at [NKUA](https://www.di.uoa.gr/). Slowly.
